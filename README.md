# 🌿 MindSolace

> **Share Your Feelings, Vent, and Find Comfort with AI & Peer Listeners.**

MindSolace is a privacy-focused mental wellness web platform designed to provide emotional support to individuals dealing with stress, loneliness, academic pressure, and emotional burnout.

The platform combines AI-assisted conversations, peer listening, mood tracking, cognitive journaling, and multilingual support to create a comfortable digital space for emotional well-being.

## ✨ Key Features

- 🤖 **AI Companion:** An empathetic conversational assistant designed to provide supportive interactions.
- 🌐 **Multi-Language Support:** Dynamic language switching between English, Hindi, and Hinglish.
- 👥 **Peer Listening Circle:** Connect with peer listeners for supportive one-to-one conversations.
- 📊 **Mood Tracker & Analytics:** Record daily mood scores and triggers and visualize mood trends using Chart.js.
- 📖 **Cognitive Thought Journal:** Write personal reflections and explore positive thought reframing using CBT-inspired techniques.
- 🛡️ **SOS Emergency Support:** Quick access to emergency support information and verified helpline resources.
- 🧘 **4-7-8 Breathing Exercise:** An interactive breathing tool for relaxation and stress management.
- 🔒 **Privacy-Focused Design:** Client-side data storage and anonymous guest access.

## 🚀 How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/simran-rana2910/mindsolace.git
```

### 2. Navigate to the Project Folder

```bash
cd mindsolace
```

### 3. Run the Application

Using Python:

```bash
python server.py
```

### 4. Open in Browser

Visit:

```text
http://localhost:8000
```

Alternatively, open `index.html` directly in a modern web browser if the required features support direct file access.

## 🎯 Project Objective

The main objective of MindSolace is to explore how web technologies and AI-assisted interactions can contribute to accessible mental wellness support.

It aims to provide a digital environment where users can express their feelings, reflect on their emotional experiences, monitor mood patterns, and access supportive resources.
