# MindSolace 🌿
> **"Share Your Feelings, Vent, and Find Comfort with AI & Peer Listeners"**

MindSolace is a compassionate, privacy-first mental health web platform designed for individuals dealing with stress, loneliness, academic pressure, or emotional burnout. It bridges the gap between technology and emotional well-being by offering an Empathetic Multi-lingual AI Companion, a Peer Listening Network, Daily Mood Tracking with Analytics, Cognitive Journaling, and Instant Crisis Support.

---

## ✨ Key Features

- **🤖 Empathetic AI Companion:** 24/7 non-judgmental conversational assistant powered by natural language emotion mining.
- **🌐 Multi-Language Support (i18n):** 1-Click dynamic switching between **English**, **हिंदी (Hindi)**, and **Hinglish** with auto-detection.
- **👥 Peer Listening Circle:** Connect safely with empathetic student and peer listeners for 1-on-1 conversations.
- **📊 Mood Tracker & Analytics:** Log daily mood scores (1-5) and triggers; visualize mood trends over time via Chart.js.
- **📖 Cognitive Thought Journal:** Write reflections and receive positive cognitive reframing (CBT technique).
- **🛡️ SOS Emergency & 4-7-8 Breathing Tool:** Instant access to 24/7 verified helplines (Tele-MANAS, KIRAN 1800-599-0019) and an interactive breathing relaxation exercise.
- **🔒 Privacy-First Architecture:** 100% Client-side encrypted persistent storage (zero-knowledge local data) with an Anonymous Guest Mode.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Modern Glassmorphic Dark/Light Theme), Lucide Icons
- **Core Logic:** Vanilla Modern JavaScript (ES6+ Modular Architecture)
- **Visual Analytics:** Chart.js
- **Audio & Speech:** Web Speech API (`SpeechRecognition` & `SpeechSynthesis`)
- **Storage:** Client-side local persistence (`localStorage` / IndexedDB abstraction)

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/mindsolace.git
   ```
2. Navigate to the project folder:
   ```bash
   cd mindsolace
   ```
3. Simply open `index.html` in any modern web browser (Google Chrome, Edge, Brave, Firefox):
   - Double click `index.html` **OR**
   - Run a lightweight local server:
     ```bash
     python server.py
     ```
     and open `http://localhost:8000` in your browser.
